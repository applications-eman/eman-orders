# Instructions for AI agents

- Work directly on `main`. Do not create or switch to other branches or open pull requests.
- Before editing, sync with the latest `origin/main`.
- After completing the requested work and checks, commit the changes and push them to `origin/main` before reporting completion.
- Never force-push or rewrite `main` history. If there are conflicts or unrelated local changes, stop and report them instead of creating another branch.
- Keep secret values, `.env` files, database credentials, and live database exports out of GitHub. Use Replit Secrets and PostgreSQL.
- Do not run `npm test`; it empties the database.
