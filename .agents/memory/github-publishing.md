---
name: GitHub publishing
description: The user's standing approval boundary for commits and pushes to this app's GitHub main branch.
---

**Rule:** Do not commit or push app changes to GitHub unless the user explicitly asks for that action.

**Why:** The user wants to review updates and choose when they are ready to commit and push to `main`.

**How to apply:** Treat connected credentials as access only, not permission to publish. Leave changes available for review until the user explicitly requests a commit or push.
